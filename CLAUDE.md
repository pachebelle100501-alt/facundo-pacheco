# Estudio — guía de trabajo

Respuestas breves y precisas. Ahorrar tokens.

## Equipos (`.claude/agents/`)
| Área | Agente |
|---|---|
| Varias áreas / no está claro | `coordinador` |
| Páginas web, SEO, deploy | `equipo-web` |
| Automatizaciones, integraciones | `equipo-automatizaciones` |
| Apps, backend, bases de datos | `equipo-apps` |
| Video y foto | `equipo-video-foto` |
| Redes sociales | `equipo-redes` |
| Dropshipping / Shopify | `equipo-dropshipping` |

## Carpetas
- `web/<sitio>/` · `apps/<app>/` · `automatizaciones/<flujo>/`
- `media/<proyecto>/{crudo,editado,final}/`
- `redes/calendario/` · `dropshipping/productos.md`
- `docs/` — guías y plugins recomendados

## Reglas comunes
- Confirmar antes de publicar, enviar, pagar, borrar o gastar créditos.
- Nada de secretos en el repo.
- Verificar el resultado antes de darlo por terminado.
